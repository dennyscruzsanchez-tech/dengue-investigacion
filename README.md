\## Descripción del proyecto



Este repositorio contiene una investigación colaborativa sobre el dengue. El proyecto reúne información relacionada con sus características, síntomas, formas de transmisión, prevención, tratamiento y situación en el Perú.



\## Objetivo



Investigar y organizar información confiable sobre el dengue para conocer sus principales características, comprender cómo se transmite y promover medidas adecuadas para su prevención.



\## Estructura del proyecto



La información está organizada en diferentes archivos y carpetas para facilitar su consulta y permitir el trabajo colaborativo de los integrantes.



\## Metodología de trabajo



El proyecto se desarrolla de manera colaborativa utilizando Git y GitHub. Cada integrante participa en diferentes partes de la investigación, realizando cambios mediante Git y registrando sus aportes mediante commits.



\## Fuentes



Las fuentes utilizadas durante la investigación serán registradas en la carpeta `fuentes`.
